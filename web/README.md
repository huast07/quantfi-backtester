# QuantiFi Backtester web app

The static Next.js site behind https://web-khaki-chi-52.vercel.app.
Pyodide workers run the `quantgen` Python package in the browser, so strategies and results never leave the user's machine.

See the [root README](../README.md) for what the backtester models, the case catalogue, and how to run, test and deploy it.
